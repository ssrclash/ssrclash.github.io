一、什么是 Quantumult X？

Quantumult X 是一款专注于网络规则分流与代理管理的高级工具。它的核心用途是：科学上网、网络加速、规则控制、流量监控、代理链路管理等。由于其强大的灵活性和稳定性，在 iOS 用户圈中广受推崇，尤其适合中高级用户或网络安全爱好者。

它不同于一般的 VPN 客户端，它更像一个小型的可编程网络路由器，你可以在里面设定谁走代理、谁走直连，甚至为不同的流量制定多级规则。这种“规则优先”的架构，让它在应对复杂网络环境时游刃有余。

二、为什么选择 Quantumult X？

在 iOS 平台上，类似的工具还有 Shadowrocket、Loon、Stash 等，但 Quantumult X 能脱颖而出，靠的正是其细腻的功能配置能力和稳定性极高的运行机制。

2.1 核心优势

  • 策略组支持：可以设置多个策略组（如自动选择、节点列表、负载均衡等）。

  • 脚本支持：通过 JavaScript 执行高级功能（如重写请求、广告拦截等）。

  • 流量分析：按时间、应用、节点等多维度进行网络使用统计。

  • 规则灵活：内建强大的“规则分流系统”，用户可轻松自定义规则优先级。

  • 轻量美观：UI 简洁，几乎无卡顿，后台运行稳定。

五、规则与策略组：玩转分流的关键

Quantumult X 的灵魂，在于分流规则与策略组配置。这是它与普通 VPN 最大的差异。

5.1 什么是策略组？

策略组是一个“逻辑集合”，用来指示某类请求要使用哪种连接方式。常见的策略组包括：

  • 直连（DIRECT）：不通过代理，直接连接；

  • 全局代理（PROXY）：所有请求走代理节点；

  • 节点列表：列出多个节点供用户选择；

  • 自动选择（AUTO）：根据延迟或负载自动切换节点；

  • 拒绝（REJECT）：拦截特定流量，常用于广告屏蔽。

5.2 自定义规则分流

你可以根据域名、IP、应用名等创建详细规则。例如：

plaintext
DOMAIN-SUFFIX,google.com,PROXY
DOMAIN-SUFFIX,baidu.com,DIRECT
PROCESS-NAME,YouTube,PROXY

这些规则将自动应用在访问过程中，实现精准控制。

✅ 小贴士：建议使用“规则分组 + GEOIP + DOMAIN”组合，可以最大程度地控制代理策略，防止误杀或漏判。

七、使用中常见问题与解决方案

7.1 Quantumult X 无法连接？

  • 检查 VPN 权限是否授权；

  • 确保节点可用（ping 不通的换个节点）；

  • 检查配置文件是否正确生效。

7.2 VPN 状态频繁断开？

  • 避免开启低功耗模式；

  • 设置中允许后台活动；

  • 尽量使用稳定节点，不建议使用公共免费节点。

7.3 如何重置 Quantumult X？

在设置页中选择“恢复出厂设置”，即可清除所有配置，回归初始状态。

7.4 能否在一个设备上安装多个版本的 Quantumult X？

官方并未推出多版本，因此只能安装一个。若需切换配置，建议保留多个 .qxconfig 文件，根据场景导入即可。

FAQ

SSR 的混淆和协议设置如何选择才能绕过封锁？
选择模拟 HTTPS 的混淆方式如 tls1.2_ticket_auth，并搭配 AEAD 或协议插件，可以有效隐藏流量特征，降低被封锁风险。不同网络环境需测试选择最优组合。
Matsuri 的多节点测速机制是怎样的？
Matsuri 使用并发测速机制，可同时对多个节点进行延迟与带宽测试。测试结果会自动排序，并可根据延迟或速度自动切换最优节点，提升连接体验。
WinXray 如何实现延迟最低节点自动切换？
WinXray 支持节点延迟检测和策略组配置，可自动将流量切换至延迟最低的节点。用户无需手动选择，提高游戏、视频和网页访问速度及稳定性，优化整体网络体验。
Shadowrocket 的节点测速如何优化连接？
Shadowrocket 测试节点延迟和丢包率，并根据结果排序策略组节点。延迟低的节点优先使用，可保证网页浏览、视频播放和游戏连接速度和稳定性，提高整体网络体验。
QuantumultX 支持哪些定制化分流策略？
QuantumultX 支持域名、IP、端口、协议以及用户自定义脚本分流。结合策略组使用，可实现广告屏蔽、视频加速、游戏优化等功能，提高访问速度和个性化网络体验。
PassWall2 的节点测速结果如何影响分流？
PassWall2 会根据节点延迟和成功率自动调整策略组选择最优节点。测速结果直接影响程序选择出口，从而提高连接速度和稳定性。
V2Ray 的 gRPC 传输方式有哪些优势？
V2Ray gRPC 传输支持多路复用和长连接，减少握手次数。它对高延迟网络和移动网络非常友好，同时可通过 TLS 加密保护数据，提高隐蔽性和稳定性。
VMess AEAD 加密如何确保数据传输安全？
AEAD 加密可防止数据篡改、重放攻击和流量特征泄露。在高封锁环境中保证节点可用，提升数据安全和连接稳定性，降低被检测风险，确保长期安全访问体验。
VLESS + XTLS 模式在高并发环境中表现如何？
XTLS 模式减少握手和加密开销，提高吞吐量和 CPU 利用率。在高并发环境下，能够保持连接稳定，适合游戏、视频和高频请求的网络场景，提高整体性能。
V2Ray 的 outbound freedom 模式有什么作用？
freedom 是直连模块，可用于分流策略中实现部分流量直连。用户可在 routing 中设置匹配规则，将国内域名或局域网 IP 指向 freedom 出口，从而减少代理开销和延迟。
